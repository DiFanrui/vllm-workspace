- GPU: NVIDIA GeForce RTX 4090, 24,564 MiB, compute capability 8.9
- InfiniLM experimental branch: `dpv4-compress`, commit `9aa937fa`

## Test-suite limitation

The repository's `modules` and `e2e` precision comparison hard-codes an internal
Python reference path:

`/data-aisoft/wangpengcheng_data/deepseek-v4-mini-1B-from-flash/code`

That reference implementation is not included in the public branch. The
Transformers DSV4 implementation cannot be substituted directly because its
checkpoint key layout differs from the tiny checkpoint generated by this test.
Therefore, this run proves kernel execution, model loading, forward, and greedy
generation on NVIDIA, but does not complete the missing-reference numerical
comparison.

## Full-model feasibility

The official DeepSeek-V4-Flash is a 284B-class MoE model with 13B activated
parameters and 1M context. The checkpoint is far beyond one 24 GB RTX 4090.
The InfiniLM branch's own full-model notes use an INT8 converted checkpoint with
TP=8 on HYGON hardware. A rough weights-only lower-bound is about 35.5 GB per
device at TP=8 before KV cache, activations, workspace, and communication
buffers, so eight 64 GB-class devices are the realistic starting point for that
exact path. This estimate is an inference, not an official minimum requirement.

Official vLLM's initial deployment recipe uses 4x B200/B300 for V4-Flash and 8x
B200/B300 for V4-Pro.
